# 💰 Salary Prediction using Simple Linear Regression

## 📌 Overview

This project demonstrates **Simple Linear Regression** using Python and Scikit-learn.

The model learns the relationship between an employee's **Years of Experience** and **Salary**, and uses this relationship to predict the expected salary for a given number of years of experience.

This is a **Machine Learning learning/mini project** created to understand the basic workflow of a regression model.

---

## 🎯 Objective

The objective of this project is to build a Simple Linear Regression model that can predict an employee's salary based on their years of experience.

**Input:** Years of Experience
**Output:** Predicted Salary

---

## 🔄 Machine Learning Workflow

The project follows these steps:

1. Import the required libraries.
2. Load the `Salary.csv` dataset using Pandas.
3. Separate the independent and dependent variables.
4. Split the dataset into training and testing sets.
5. Create a Simple Linear Regression model.
6. Train the model using the training data.
7. Make predictions using the test data.
8. Visualize the training and testing results.
9. Take years of experience as user input.
10. Predict the expected salary using the trained model.

---

## 🤖 Model Used

### Simple Linear Regression

Simple Linear Regression is used to understand the relationship between one independent variable and one dependent variable.

In this project:

```text
Independent Variable → Years of Experience
Dependent Variable   → Salary
```

The model learns this relationship from the training data and uses it to make salary predictions.

---

## 📊 Dataset

The project uses a salary dataset stored in:

```text
Salary.csv
```

The dataset contains information about:

* Years of Experience
* Salary

The dataset is divided into:

* **80% Training Data**
* **20% Testing Data**

A fixed `random_state` is used so that the train-test split remains reproducible.
